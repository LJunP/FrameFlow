# F11 人工标注、盲评与一致性协议

## 1. 标注单位与标签

每个候选独立标注，Reviewer 只能看到随机 `blind_review_id`、不可变 Brief 和媒体：

| 字段 | 可选值 | 判定标准 |
|---|---|---|
| `quality_label` | `EXCELLENT` | 满足 Brief，可直接进入优选候选；不是“我喜欢” |
|  | `ACCEPTABLE` | 基本满足 Brief，有轻微问题但不构成明显缺陷 |
|  | `DEFECTIVE` | 命中预注册明显缺陷 taxonomy |
|  | `UNREVIEWABLE` | 媒体损坏/打不开；不能猜成视频质量差 |
| `obvious_defect` | true/false/blank | 只按 taxonomy；不可审时 blank |
| `review_notes` | 简短事实 | 写时间码/现象，不写机器猜测 |

明显缺陷 taxonomy 在试点前冻结，至少覆盖：时长、比例/分辨率、黑帧、冻结、静音/
无音轨、乱码/水印、主体严重畸形、与 Brief 明显不符。新增类别只能进入下一轮协议，
不能为当前结果临时改答案。

## 2. 盲评流程

1. Evidence custodian 用 manifest candidate 集和固定 seed 生成随机 blind ID；
2. A/B 两份包字段完全相同，只含 blind ID、媒体入口、Brief、标签列；
3. 隐藏 candidate ID、原文件名语义、机器状态、Finding、分数、排名、机器选择和
   预期异常；
4. A/B 独立完成，不聊天、不看另一份，不由 Operator 提示“机器觉得哪里有问题”；
5. 提交后立即保存 CSV bytes、SHA-256、Reviewer ID、提交时间，原文件只读冻结；
6. 只有两份原始提交锁定后，裁决员才看到分歧项与两边 notes；
7. `adjudicated.csv` 叠加裁决标签，不覆盖 A/B 原标签；
8. 机器结果最后才与 blind ID 映射 join，用于统计。

## 3. 抽样规则

- 交付候选：建议全量做交付后缺陷复核；
- `AUTO_REJECT`：数量允许时全量盲审；否则按批次做等概率简单随机抽样，seed、总体数、
  抽样数和抽中 ID 哈希在看结果前固化；
- 重复排除单独审计聚类正确性，不混入质量误杀分母；
- `ANALYSIS_ERROR`/`INVALID` 属系统/输入错误，单列，绝不算视频质量淘汰；
- 不允许方便抽样、只抽有缩略图的媒体或在看过机器结论后补抽“代表样本”；
- 分层/不等概率抽样需要预先定义权重；当前统计器只对 census 或等概率样本做直接比例。

## 4. 一致性与裁决

报告同时给出 raw agreement 与 Cohen's κ：

- 可比样本为 A/B 都有非空标签的 blind ID 交集；缺失/未配对数量单列；
- 所有可比标签完全单一时，期望一致率为 1，κ 输出 N/A（`NO_LABEL_VARIANCE`）；
- 可比样本小于 30 时强制小样本警告；
- κ ≥ 0.80：强一致；0.60–0.79：可用但审查分歧；< 0.60：先复训 Reviewer、澄清
  taxonomy，并对新样本重评；这些只是协议质量阈值，不是产品价值结论；
- 裁决率、缺失率和 Reviewer 用时也保留，不能只展示 κ。

## 5. CSV 字段边界

原始 Reviewer 文件：

```csv
blind_review_id,quality_label,obvious_defect,review_notes
```

合并后的裁决/运营文件：

```csv
candidate_id,batch_id,blind_review_id,machine_disposition,operational_full_watch,baseline_full_watch_seconds,assisted_review_seconds,selected_for_delivery,audit_included,adjudicated_quality,delivery_obvious_defect,review_notes
```

blank 表示未知，不能写成 false/0。`baseline_full_watch_seconds` 是没有 FrameFlow 时
完整审核该候选所需的预注册基线秒数，`assisted_review_seconds` 是实际运营审核秒数；
两者必须来自同一候选口径。`operational_full_watch` 只是辅助动作指标。为建立 ground
truth 而做的独立盲评观看时间必须单列，不能混入 assisted 运营负担，否则节省率会被
评测过程本身污染。

## 6. 质量控制

- 首批先做 5–10 条训练集，讨论后丢弃训练标签，再开始正式盲评；
- 每个 Reviewer 的媒体播放失败单列 `UNREVIEWABLE` 并报技术事件；
- notes 出现机器术语、候选真实 ID 或另一 Reviewer 观点时，该条盲性受损；
- 重复 blind ID、重复 candidate ID、未知枚举、非布尔文本由脚本直接拒绝；
- 有分歧并不代表谁“错”；只允许裁决层生成最终标签，原始层不可改写。
