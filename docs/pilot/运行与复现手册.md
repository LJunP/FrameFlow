# F11 本地彩排与未来真实报告运行手册

## 1. 当前可直接运行：合成彩排

前提：Python 3.11+，以及本机 `ffmpeg/ffprobe` 或已经存在的固定 Digest Docker
FFmpeg 镜像。脚本使用 `--pull=never` 和 `--network=none`，不会联网拉镜像。

```bash
./scripts/pilot/run-synthetic-rehearsal.sh
python3 -m unittest discover -s tests/pilot -v
```

默认可再生数据：`experiments/pilot/generated/synthetic-rehearsal/`；稳定 Evidence：
`experiments/pilot/evidence/synthetic-rehearsal/`。每次重跑只替换这两个精确子目录，
拒绝 symlink 与路径逃逸。

核验：

```bash
python3 -m json.tool experiments/pilot/evidence/synthetic-rehearsal/receipt.json >/dev/null
python3 -m json.tool experiments/pilot/evidence/synthetic-rehearsal/report.json >/dev/null
sed -n '1,220p' experiments/pilot/evidence/synthetic-rehearsal/report.md
```

## 2. 未来真实 intake（本轮不得执行）

只有在所有者已对精确数据和真实 Provider 调用作出当次确认后，才在仓库外受控目录
准备 `manifest.json`，并运行：

```bash
python3 scripts/pilot/validate_real_pilot_intake.py \
  --dataset-root "$AUTHORIZED_PILOT_ROOT" \
  --output "$AUTHORIZED_PILOT_ROOT/evidence/intake-validation.json" \
  --confirm-authorized-intake
```

脚本拒绝仓库内真实数据、绝对/逃逸路径、symlink、hash 不符、缺审批/删除日期和缺
真实调用 Evidence。输出只含聚合数与哈希，不回显客户、媒体路径或 Provider 配置。

## 3. 未来真实指标（完成盲评与裁决后）

```bash
python3 scripts/pilot/calculate_metrics.py \
  --annotations "$AUTHORIZED_PILOT_ROOT/annotations/adjudicated.csv" \
  --reviewer-a "$AUTHORIZED_PILOT_ROOT/annotations/reviewer-a.csv" \
  --reviewer-b "$AUTHORIZED_PILOT_ROOT/annotations/reviewer-b.csv" \
  --batch-runtimes "$AUTHORIZED_PILOT_ROOT/annotations/batch-runtimes.json" \
  --classification REAL_PILOT \
  --output "$AUTHORIZED_PILOT_ROOT/evidence/metrics.json"
```

报告生成器需要同分类的 `metrics`、`validation`、`provenance` 与脱敏 dataset summary；
所有文件留在受控根：

```bash
python3 scripts/pilot/generate_report.py \
  --metrics "$AUTHORIZED_PILOT_ROOT/evidence/metrics.json" \
  --validation "$AUTHORIZED_PILOT_ROOT/evidence/intake-validation.json" \
  --provenance "$AUTHORIZED_PILOT_ROOT/evidence/provenance.json" \
  --dataset-summary "$AUTHORIZED_PILOT_ROOT/evidence/dataset-summary.json" \
  --json-output "$AUTHORIZED_PILOT_ROOT/evidence/report.json" \
  --markdown-output "$AUTHORIZED_PILOT_ROOT/evidence/report.md"
```

生成器只给描述性结果和不确定性，不自动作出所有者专属的价值/项目终态判断。

## 4. 故障排查

| 现象 | 含义/处理 |
|---|---|
| pinned image unavailable | 安装本机 FFmpeg 或由所有者准备固定镜像；脚本不会自动 pull |
| invalid/truncated probe unexpectedly succeeds | FFmpeg 行为或夹具变了；保留 FAIL receipt，检查工具版本 |
| zero denominator | 没有可用观察；补授权样本，不得填 0 |
| missing values present | 报告只计算 observed cases 并列缺失数；回查原始事件/标注 |
| κ 为 N/A | 无可比标签或标签无方差，不是脚本故障 |
| real intake rejected as repository path | 把真实数据移到仓库外受控根，不要放宽守卫 |
| report classification mismatch | 四个输入混入合成/真实分类；停止并重建，不做字段手改 |

## 5. 结束清单

- 合成 Docker 任务使用 `--rm`，没有常驻服务；
- 本轮不得启动真实 Provider，也不得读取真实客户媒体；
- 真实试点完成后按 manifest 日期删除媒体/派生帧并生成删除 receipt；
- 对外只分享审批允许的脱敏聚合报告。
