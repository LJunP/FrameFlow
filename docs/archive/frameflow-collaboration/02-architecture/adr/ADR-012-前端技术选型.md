# ADR-012：前端技术选型

> 状态：DECISION（已由本次用户直接授权批准，2026-08-20）
> 关联：PRD 第 7.1 节前端阶段计划、development-plan-p0-m17.md 第 5 节、概要设计第 2.1 节

## 背景

FrameFlow 的 PRD 原表述为"后端/API 优先，前端先用 API 工具或极简管理页"，前端框架长期处于"待确认项"。随着 M01 完成和产品主线推进，需要锁定前端技术选型，使项目从纯后端 API 演进为可演示的全栈项目。

## 决策

前端采用以下技术栈：

```text
语言：TypeScript
框架：React
元框架：Next.js（App Router + BFF）
样式：Tailwind CSS
组件：shadcn/ui
HTTP：TanStack Query（缓存/重试/loading）
状态管理：Zustand（轻量）
类型生成：openapi-typescript（从后端 OpenAPI YAML 生成 TS 类型）
```

本 ADR 锁定技术方向，不长期锁定会过期的大版本。每个前端 Task 派发时，必须选当时官方受支持的稳定版，将 Node.js、包管理器、React、Next.js、Tailwind CSS、TanStack Query 与 openapi-typescript 的精确版本写入 Task Capsule、`package.json` 和 lockfile；禁止用 `latest`、`next` 或无 lockfile 派发。

## 理由

1. **TypeScript**：类型安全，与后端 Java 的类型思路一致，面试标准要求。
2. **React**：生态成熟，与 Next.js 配套；精确版本交给派发时的受支持性核验。
3. **Next.js App Router/BFF**：在同源边界内承接 Cookie、Token 轮换和后端 API 转发，避免浏览器 JavaScript 持有 Refresh Token。
4. **Tailwind CSS + shadcn/ui**：学习曲线低、设计感好、源码可控（非传统黑盒组件库），面试展示加分。
5. **TanStack Query**：缓存、重试、loading 状态管理，与后端幂等契约和 REST API 天然契合。
6. **Zustand**：轻量状态管理，不上 Redux 的复杂度。
7. **openapi-typescript**：后端已有手写 OpenAPI YAML 权威契约，直接生成 TS 类型，前后端契约不漂移。

## 不选什么

| 不选 | 原因 |
|---|---|
| Vue 3 | 用户明确选择 React 方向 |
| Nuxt 3 | 已选 React 方向 |
| Ant Design / Element Plus | 黑盒组件库，长得都一样，面试辨识度低 |
| 纯 JavaScript | 无类型安全，面试无竞争力 |
| Redux | 过重，当前场景不需要 |

## 前端阶段计划

前端位于本仓库 `frameflow-web/`，与 Java 模块共用同一 Git 边界，但不进入 Maven 模块树。

| 阶段 | 前置 | 目标 |
|---|---|---|
| M01-F / FF-M01F-001 | `FF-M01H-001=DONE` | 前端基座、BFF、认证与团队界面 |
| M04-F / FF-M04F-001 | M01-F 及 M02/M03/M04-A DONE | 项目/Brief、任务/评论、素材界面 |
| M08-F / FF-M08F-001 | M04-F 及 M07/M08 DONE | 审核、基础通知、交付与产品 MVP Gate |

## 前端不做

```text
浏览器内视频剪辑器
实时协同编辑
移动端 App
复杂炫酷动画/3D 渲染
```

## 约束

- 前端不修改后端权威契约（`docs/04-api/openapi/frameflow-v1.yaml`）；契约冲突时上报。
- 只使用 openapi-typescript 从 OpenAPI YAML 生成 TS 类型，不并行引入 orval，不手写重复类型。
- Browser 只访问同源 Next BFF；BFF 再访问 Spring Boot API。Refresh Token 只存入 `Secure`/`HttpOnly`/`SameSite` Cookie，严禁 localStorage、sessionStorage 和 IndexedDB；状态变更请求必须有 CSRF 防护。
- 后端为每次 HTTP attempt 生成并覆盖 `X-Request-Id`，前端不将它当作稳定业务 ID。需要串联多次请求时，单独使用受长度/字符集校验的 `X-Correlation-Id`；该 header 尚需 M02 Contract Gate 决定是否写入权威 OpenAPI。
- 本仓库保持单仓模式；`frameflow-web/` 不加入 Maven reactor，但必须进入同一 CI、任务权限和证据边界。
