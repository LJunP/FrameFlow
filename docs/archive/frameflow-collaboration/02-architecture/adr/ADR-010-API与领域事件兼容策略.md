# ADR-010：API 与领域事件兼容策略

- 状态：Accepted
- 日期：2026-08-11

## 决策

- 外部 API 使用 `/api/v1`；破坏性变更升级版本。
- 非破坏性字段只能以可选字段追加；删除字段前经过弃用窗口。
- 领域事件必须包含 `eventId`、`eventType`、`schemaVersion`、`occurredAt`、`producer` 和脱敏业务标识。
- 消费者必须忽略未知字段，生产者不得无通知删除必需字段。
- 每次契约变更同时更新 OpenAPI/事件目录、契约测试和证据索引。

## 后果

服务可以独立发布和回滚，但需要维护兼容窗口、事件 schema 和消费者回归测试。
