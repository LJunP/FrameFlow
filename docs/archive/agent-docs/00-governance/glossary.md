# FrameFlow Select 术语

- **Project**：持续的商品或营销内容目标。
- **Quality Profile**：可版本化的质检规则、自动化政策与排名权重。
- **Batch**：同一 Prompt/Brief 目的下的一批候选视频。
- **Candidate**：批次中的不可变视频候选。
- **Analysis Run**：使用固定 Pipeline/Detector/Prompt 版本的一次分析。
- **Finding**：带规则、严重度、置信度和证据的问题或满足项。
- **Quality Vector**：分维度质量结果。
- **Ranking Snapshot**：固定候选集合与配置上的不可变排名。
- **Selection Set**：人工确认的 Top-K 候选集合。
- **Eligibility Gate**：决定候选是否进入人工优选池的硬规则。
- **Review**：需要人工判断，不能自动视为通过或淘汰。
