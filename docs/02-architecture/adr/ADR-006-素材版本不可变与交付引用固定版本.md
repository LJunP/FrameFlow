# ADR-006：素材版本不可变与交付引用固定版本

- 状态：Accepted
- 日期：2026-08-11

## 背景

视频素材会被返工、重新编码和重新审核。原地覆盖会破坏审核、授权和交付追溯。

## 决策

- `Asset` 表示逻辑素材，`AssetVersion` 表示不可变版本。
- 任何修改创建新版本，不覆盖已存在的对象或版本记录。
- `DeliveryItem` 必须保存 `pinned_asset_version_id`。
- 锁定交付版本不可删除或覆盖；返工必须回到新版本并重新审核。

## 后果

- 审计和回滚更清晰；
- 存储和清理逻辑更复杂，需要孤儿对象补偿；
- 交付查询必须显式区分当前版本与固定版本。
