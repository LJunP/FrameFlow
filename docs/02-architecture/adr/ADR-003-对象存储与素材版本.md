# ADR-003：MinIO 保存媒体，对象版本由数据库管理

- 状态：已批准
- 日期：开发前基线

## 决策

媒体二进制数据存入 MinIO；PostgreSQL 保存对象键、校验和、MIME、版本、归属和审核元数据。素材版本不可原地覆盖。

## 原因

- 视频、图片、音频和交付包不适合直接存进主业务数据库；
- MinIO 提供 S3 兼容对象存储和预签名 URL；
- 版本不可变使审核、交付和回溯可审计。

## 后果

- 下载前必须校验项目权限，再签发短期 URL；
- 文件上传与数据库写入不假设原子性，必须有补偿或待处理状态；
- 交付包固定引用具体 `AssetVersion`。
