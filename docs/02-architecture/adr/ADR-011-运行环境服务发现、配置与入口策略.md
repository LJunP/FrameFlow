# ADR-011：运行环境服务发现、配置与入口策略

- 状态：Accepted
- 日期：2026-08-11

## 决策

- 模块化单体：Spring Profile/环境变量，无服务发现。
- 微服务 Compose：Nacos 负责服务发现和非敏感配置，Gateway 负责统一应用入口。
- Kubernetes：Kubernetes Service DNS、ConfigMap、Secret；Nginx Ingress 负责基础入口，Gateway 负责应用路由。
- Istio：沿用 Kubernetes Service DNS；Istio Gateway/VirtualService/DestinationRule 负责网格入口、版本路由和灰度；mTLS/AuthorizationPolicy 负责服务间安全。
- 同一环境不同时启用多个同职责的重试策略；应用重试和网格重试必须明确主责。

## 后果

不同环境可以体现技术迁移，而不会把 Nacos、Kubernetes 和 Istio 混为同一层能力；配置和入口迁移需要单独测试。
