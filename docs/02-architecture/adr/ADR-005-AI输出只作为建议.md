# ADR-005：AI 输出只作为 Suggestion

- 状态：已批准
- 日期：开发前基线

## 决策

AI Provider 返回的摘要、分镜建议、标签和字幕摘要先保存为 Suggestion。只有拥有相应权限的人类确认后，才可影响正式 Brief、任务、素材或交付数据。

## 原因

- AI 输出可能不准确、越权、泄露敏感信息或不符合客户意图；
- 人工确认能保留创作和业务责任边界；
- Suggestion 与正式数据分离，便于审计、回滚和比较。

## 后果

- AI 输入必须脱敏、最小化并记录 Provider/模型/模板版本；
- AI 调用有超时、限流、有限重试和成本记录；
- 产品 AI 链路与 Stinky Cobbler 研发 Agent 控制面保持隔离。
