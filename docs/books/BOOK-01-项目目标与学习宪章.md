# BOOK-01:项目目标与学习宪章(唯一权威,不可增删版本)

## 1. 项目为什么存在

目标优先级永久固定,不可颠倒:
1. 项目所有者本人从零建立真实的软件工程能力;
2. 完成一个真实可用的 AI 原生视频质检产品;
3. 形成可用于求职展示的完整工程项目。

项目成功必须同时满足三条主线:个人能力线、工程交付线、产品价值线。任何一条未完成,都不能宣布整个学习项目完成。

## 2. 判定误区(禁止用以下标准宣布成功)
- 代码是否存在、Agent 是否宣布完成、测试数量、文档完整度、页面能打开、本地合成数据跑通——这些只是工程信号,不是学习目标达成信号。

## 3. 产品定义与边界
- 产品:面向 AI 生成短视频团队的批量质检、问题定位、重复聚类、质量评估、批次排名与 Top-K 优选平台。
- 目标用户:批量生成 AI 电商短视频的个人创作者、AI 内容工作室、电商广告素材团队、小型 MCN、AI 视频生成服务团队。
- 核心价值:一次生成几十至几百条视频后,快速淘汰明显不合格与高度重复的候选,把最值得人工观看的候选筛选出来,同时尽量避免错误淘汰真正优秀的视频。
- 产品不负责:生成视频、浏览器内剪辑、自动发布、预测爆款、替代最终人工审核、通用内容安全审核、通用 Agent 平台、Agent Infra、软件工程 Agent 调度、训练基础大模型、微服务技术展示。

## 4. SourceLens-AIOS 边界(严格分离)
- SourceLens-AIOS = Agent 软件工程基础设施;
- FrameFlow Select = 使用多模态 AI 解决视频质检问题的垂直产品;
- 禁止把 SourceLens-AIOS 的通用 Agent 权限、沙箱、调度、治理功能复制进本产品。

## 5. 核心业务流程(固定)
Project 到 Prompt/Brief 到 Quality Profile 到 Generation Batch 到 批量上传 Candidate Videos 到 确定性视频质检 到 AI 语义质检 到 时间码/关键帧 Evidence 到 重复视频聚类 到 批次排名 到 Top-K 推荐 到 人工复核 到 锁定 Selection Set 到 导出结果。

## 6. 完成定义
- 学习项目最终状态:LEARNING_PROJECT_COMPLETE,只能由项目所有者批准;Agent 无权自行设置。
- 产品价值结论只能来自真实视频、真实模型、真实人工审核验证(PILOT_VALUE_PROVEN / PILOT_NOT_PROVEN)。
